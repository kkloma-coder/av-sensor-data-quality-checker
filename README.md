# 自动驾驶传感器日志数据质量检测工具

## 项目背景

自动驾驶系统依赖大量传感器数据进行训练和验证，数据本身的质量（是否有缺失、异常、时间戳错乱等问题）直接影响模型效果和测试结论的可靠性。本项目实现了一个轻量级的**数据质量Checker**，对模拟的车辆传感器运行日志进行自动化检测，输出结构化质量报告。

## 功能

对传感器日志CSV文件，自动检测以下四类常见数据质量问题：

1. **缺失值检测**：逐字段统计缺失数量与占比
2. **超范围异常值检测**：基于物理合理性判断数值是否越界（如车速为负、超过合理上限）
3. **时间戳连续性检测**：检测采样间隔异常跳变、时间戳乱序（倒退）
4. **重复记录检测**：识别完全重复的日志行

检测完成后输出：
- `quality_report.md`：结构化的Markdown质量报告
- `quality_summary.png`：问题数量汇总可视化图表

## 项目结构

```
.
├── generate_sample_data.py   # 生成模拟传感器日志（含故意注入的典型数据问题）
├── data_quality_checker.py   # 核心质量检测逻辑
├── sensor_log.csv            # 生成的模拟数据（运行脚本后产生）
├── quality_report.md         # 检测报告（运行脚本后产生）
└── quality_summary.png       # 汇总图表（运行脚本后产生）
```

## 运行方式

```bash
pip install pandas numpy matplotlib
python3 generate_sample_data.py      # 生成模拟数据
python3 data_quality_checker.py      # 运行质量检测，生成报告和图表
```

## 设计说明

- 每类检测封装为独立函数，输入统一为 DataFrame，输出为结构化字典，便于后续扩展新的检测规则（例如GPS漂移检测、传感器状态异常统计等），无需改动已有逻辑。
- 异常值判断阈值基于常识设定（如车速0-200km/h），真实业务场景中应替换为测试/车辆工程团队提供的标准阈值。
- 数据为脚本生成的模拟数据，非真实车辆数据，重点在于验证检测逻辑的正确性与工程实现方式。
